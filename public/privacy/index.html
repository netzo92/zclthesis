ZCLTHESIS / PRIVACY

Privacy & analytics

A small amount of measurement. A choice in your browser.

We count visits to the thesis and network pages, and clicks on the NonKYC buy link. The dashboard is private to the site administrator. We do not receive NonKYC account, registration, deposit, or trading information.

What is collected

Each event contains a random event identifier, random browser and session identifiers, the page category, a broad traffic-source category (such as search, social, or direct), and whether it was a page view or buy-link click. The server adds the time in UTC. Browser and session identifiers are hashed before storage. We do not put IP addresses, full referring URLs, search terms, wallet addresses, or keys in the analytics database. Hosting infrastructure may keep standard request and security logs separately.

What stays in your browser

A first-party random browser identifier is stored in localStorage for up to 30 days. A session identifier is kept in sessionStorage and renewed after 30 minutes without a measured event; another tab can count as another visit. The identifiers are used only for this site. We do not fingerprint your device or set analytics cookies. Clearing storage or using another browser can count you again.

Retention and limits

Events are retained for the current UTC day and the preceding 89 days, then removed on the next daily maintenance pass. Counts are estimates: visitors who disable JavaScript or analytics, send Do Not Track or Global Privacy Control, or block the requests are not counted. Obvious automated browser traffic is excluded, but bots can still affect totals.

The offline wallet stays offline

The downloadable wallet has no analytics code and makes no network requests. Generating a wallet or viewing a key is never an analytics event.

Your choice

Checking this browser’s preference…

This preference applies to this browser and website origin. Disabling analytics removes its local identifiers and stops future collection; it does not delete earlier, anonymous events. A browser privacy signal always takes precedence. The language preference is separate.
